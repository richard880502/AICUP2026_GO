## What changed

The original 400-question Public and 400-question Private answers are bytewise
preserved at the per-pool prediction-file level. The new Public and Private
400-question predictions all changed. For each new 600-player pool, frozen
models trained on the corresponding original 400-player/100-game pool produce
embeddings; the classifier head is unused. Source normalization is retained.
Candidate centroids use all ten available reference games; question centroids
use each actual 1/2/3/5-game query. Top-20 features feed the frozen source
group-softmax reranker.

The new candidate libraries provide player IDs, so held-out candidate games
can select dimension blends and reranker strengths without query-test labels.
These selection diagnostics are not independent validation. The corresponding
Stage-1 comparisons and reranker-selection results are recorded in
[FROZEN_RESULTS.md](../production_pipeline/FROZEN_RESULTS.md).

## Interpreting the earlier 0.923040

That result is a historical independent 400-way, black-only proxy with 100
reference games per player and 5/10/15/20 query games. Official v2 also includes
600-way, ten-reference-game, mixed-color pools with 1/2/3/5 query games, and
weights original/new Public questions equally. The historical score does not
predict official v2 performance. The weak new-pool selection scores around
0.05 should have been disclosed before the first upload was described as the
best-method submission.
