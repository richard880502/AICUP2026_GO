# Frozen ArcFace hard-negative reranker

This experiment is isolated from `aicup_tutorial_review` and does not alter
the official tutorial reproduction. It targets only the strongest local
ArcFace 512D/1024D ensemble (`query_proxy=0.9161533072`).

The ArcFace encoders and the published cross-dimensional blend are frozen.
Synthetic queries are generated by holding 5/10/15/20 games out of each
candidate player's 100 games. Query-owner players use a deterministic 80/20
train/validation split. Hard negatives come from frozen Stage-1 Top-K results.
The independent query labels are not used for training, feature selection,
Top-K selection, or hyperparameter selection. See `RESULTS.md` for the frozen
first-run result, group-softmax result, and separately reported per-query-size
ablation.

Run from the project root:

```bash
.venv/bin/python -m experiments.reranker.build_embedding_cache --device cuda:1
.venv/bin/python -m experiments.reranker.run_experiment \
  --device cuda:1 \
  --samples-per-count 2 \
  --top-k 20 \
  --weight-mode global \
  --output experiments/reranker/results/first_reranker.json
```

The per-query-size ablation uses the same command with
`--weight-mode per-count` and output `results/per_count_reranker.json`.

The current-best group-aware run uses:

```bash
.venv/bin/python -m experiments.reranker.run_group_mlp \
  --device cuda:1 \
  --samples-per-count 4 \
  --top-k 20 \
  --output experiments/reranker/results/group_softmax_mlp.json
```

Artifacts and results remain under this directory. The first version uses 24
features: eight Stage-1 context values plus sixteen 1024D game-to-game matching
statistics. The baseline model is scikit-learn histogram gradient boosting so
the experiment is reproducible without adding packages to the preserved venv.

The strongest completed reranker result is `query_proxy=0.9230399459`, up from
the exactly reproduced Stage-1 value `0.9161533072`. It uses a shared
64/32-unit MLP and one-positive-among-Top-20 group-softmax loss. Candidate-only
validation selected epoch 18 and a neural score weight of 1.0 before the
independent cohort was evaluated once.
